Lean proofs.** This repository accompanies Alexander Kolpakov's manuscript
*Butson towers and high-rank Hadamard matrices*.

## Results

A real Hadamard matrix of order $n$ has entries in $\{1,-1\}$ and satisfies
$HH^{\mathsf T}=nI_n$. It has rank $n$.
The thirty-four new orders are

**7572, 17668, 22716, 32812, 42908, 58052, 73196, 78244, 93388, 98436, 108532, 118628, 128724, 133772, 148916, 153964, 169108, 174156, 184252, 199396, 229684, 234732, 244828, 259972, 275116, 295308, 320548, 386172, 2985892, 4772884, 13001124, 15131380, 38816596, 291145924.**

Here and in the paper, “new” means new to the best of the author's knowledge;
prior constructions located are recorded in the [dated literature ledger](docs/HADAMARD_HIGHER_ORDER_RECORDS.md).

The nine families give a matrix for **every integer $r\geq0$**:

| Hadamard order | Source recurrence |
|---|---|
| $7572\cdot5^r$ | Spence, $q=5$ |
| $17668\cdot13^r$ | Spence, $q=13$ |
| $22716\cdot17^r$ | Spence, $q=17$ |
| $32812\cdot3^r$ | Sixth-root source tripling |
| $78244\cdot61^r$ | Spence, $q=61$ |
| $128724\cdot101^r$ | Spence, $q=101$ |
| $153964\cdot121^r$ | Spence, $q=121$ |
| $174156\cdot137^r$ | Spence, $q=137$ |
| $15131380\cdot109^r$ | Spence, $q=109$, starting at its first expansion |

Each family has a new initial order. Individual known members, including
885924 and 18629644, are identified in the ledger. The construction campaign
also recovers **31 known orders**, for **65 distinct completed orders** in total.
The [separate known-order table](docs/sphinx/known-orders.md) gives positive
prior constructions for all 31. Our order-885924 sixth-root representative is
inequivalent to the standard Paley matrix: their ranks modulo 3 are 246090
and 442962. Equivalence at the other recovered orders remains unsettled.
There is a separate new [periodic T-matrix construction of order 127](artifacts/t-matrices-127/README.md).

Current [construction searches](docs/LOW_ORDER_SEARCH.md) target missing
order **2676** first, through length-223 periodic T-matrices. Search candidates
are kept separate from the completed results above.

The [multiplier scan](docs/HADAMARD_FRAME_TARGET_SCAN.md) also selects larger
inputs with fewer independent variables. Its newly verified prime-1951 chart
uses a multiplier of order 39 and typically leaves 23 free sign bits;
candidate output orders include 23412, 54628 and 101452.

The [complete source inventory](docs/SOURCE_INVENTORY.md) records the four
compatible sixth-root seed orders, the 27 original cyclic inputs, the 19
additional compatible inputs and the recurrence sources. Its
[65-order ledger](certificates/scalar-lift/completed-order-inventory.json)
deduplicates repeated constructions.

## Construction

The main finite input is an explicitly specified function on
$\mathbb Z/631\mathbb Z$ taking values in the eight signed standard basis
vectors of $\mathbb Z^4$. Its four coordinates have disjoint supports and
an exact summed periodic correlation identity. These data produce four
matrices with entries $0,1,-1$. At each position, exactly one of the four
matrices has a nonzero entry. Their proved Gram identities allow substitution
of the verified source matrices, including those generated by the recurrences,
to obtain the thirty-four orders and nine families.

The same input supplies a rational action of the sixth roots used in a
Butson source. Restricting scalars preserves orthogonality with its trace
metric. The final sign entries and the equality between Gram scale and
expanded order are proved separately. Intermediate matrices may have
unequal entry magnitudes.

“Butson towers” is our name for chains of these scalar restrictions.
Eight output families use Spence's classical source recurrence; the ninth
uses classical sixth-root source tripling. The
[foundations note](docs/FOUNDATIONS.md) gives the earlier scalar-morphism
references and attribution. The immediate starting reference was
[Egan–Ó Catháin, *On complete morphisms of Butson Hadamard matrices*](https://doi.org/10.1002/jcd.70047).

The [Sphinx manual](https://sashakolpakov.github.io/butson_towers/) follows the
whole argument: exact T-matrix input, disjoint orthogonal design, scalar
action and trace metric, final sign entries, and the resulting orders and
families. Proofs appear beside the code, data contracts and replay checks
that implement them. The [lower-order search](docs/LOW_ORDER_SEARCH.md) includes exact
SAT and CP-SAT sign solvers for lengths 167 and 179.

Every finite input and recurrence needed for the results is printed in the
**current paper**. Large matrices have exact entry recipes and algebraic
proofs, so verification does not require storing their dense expansions.

## Reproduce the calculations

For the repository tools, use **Python 3.11 or later**:

```sh
git clone https://github.com/sashakolpakov/butson_towers.git
cd butson_towers
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .
python scripts/verify_manuscript_data.py
python scripts/check_lean_literal_data.py
python scripts/check_lean_additional_sources.py
python scripts/audit_known_order_provenance.py --check
python -m experiments.scalar_lift.known_order_comparisons \
  --check certificates/scalar-lift/known-order-paley-comparison.json
```

The first check uses only Python's standard library and verifies the literal
finite inputs in the manuscript. The next two compare the original and
additional public inputs with their Lean literals. The last two replay the
31-order provenance record and the separate order-885924 rank comparison;
the comparison uses NumPy for exact arithmetic modulo 3.

The [current revision package](release/hexagon_2611_01070_manuscript/README.md)
contains the manuscript; the code, data and proof replays remain in this
repository, cited in the paper. The earlier submitted archive retains its
original 18-order, six-family scope. Replay
that historical package in a fresh temporary directory with:

```sh
python release/butson_towers_v3/verify.py
```

This reconstructs the order 7572 matrix, checks all **28,663,806** distinct
row pairs, and replays the finite sources, recurrences and trace audit.
The archive also works independently of this repository; its
[README](release/butson_towers_v3/README.md) lists the standalone commands.

To run the full repository test suite, install the additional test and
search dependencies:

```sh
python -m pip install -e '.[dev,native,search]'
./scripts/run_tests.sh
```

The [original submission audit](release/butson_towers_v3/audit.json) records
326 passing tests and 4 passing subtests for that earlier source snapshot.
The command above checks the current checkout.

## Read and build the documentation

Read the [hosted manual](https://sashakolpakov.github.io/butson_towers/)
or download its [PDF](https://sashakolpakov.github.io/butson_towers/butson-towers-manual.pdf).
The [documentation workflow](.github/workflows/docs.yml) rebuilds and publishes
both after relevant changes on `main`, once all documentation checks pass.

The manual includes a complete small H84 example, the scalar-restriction
and endpoint proofs, the finite-field/sign solvers, implicit families,
checkpointed campaigns, Lean verification and a source-linked API reference.
Its chapters follow the construction rather than separating mathematical
and implementation material.

```sh
python -m pip install -e '.[docs,dev]' -c docs/requirements.txt
./scripts/build_docs.sh html
./scripts/build_docs.sh doctest
```

Open `docs/_build/html/index.html`. For the printable manual, install
XeLaTeX and `latexmk`, then run `./scripts/build_docs.sh pdf`; the output is
`docs/_build/latex/butson-towers-manual.pdf`. The build treats unresolved
references and documentation warnings as errors. Generated files and local
research state are excluded from Git.

## Verify the Lean proofs

The formal development proves **all thirty-four existence statements and all
nine stated families for every nonnegative parameter**, from literal finite witnesses.
It checks signs, correlations, source norms, the matrix constructions and
all recurrence steps. The
[paper-to-Lean audit](docs/MANUSCRIPT_LEAN_AUDIT.md) follows the actual proof
chain and records its conventions and scope.

With elan/Lake installed, run:

```sh
./scripts/check_formal.sh
```

The project pins **Lean 4.32.0** and mathlib revision
`81a5d257c8e410db227a6665ed08f64fea08e997`. The axiom audit checks 85
selected statements from the original development, 10 sixth-root matrix
identities and 48 additional source, endpoint and family statements (143
selected reports in total). Only Lean's standard `propext`,
`Classical.choice` and `Quot.sound` occur.

Three source-only packages provide isolated reproduction instructions and
fresh extracted verification records:

- [Current additional sources and all proof dependencies](release/additional_source_verification/README.md).
- [Original existence development](release/lean_verification/README.md).
- [Ten sixth-root matrix identities](release/lean_sixth_root_pair/README.md).

The [formalization guide](docs/FORMALIZATION.md) gives the named theorems,
dependency setup and exact scope.
