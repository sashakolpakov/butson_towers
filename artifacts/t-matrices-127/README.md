# Periodic T-matrices of order 127

This bundle specifies four circulant matrices `T_0,...,T_3` of order 127,
with disjoint supports, entries in `{-1,0,1}`, and

\[
\sum_{i=0}^3 T_iT_i^T=127I.
\]

They provide the periodic T-matrix ingredient listed as the smallest open
T-matrix order in Egan–Kotsireas–London–Ó Catháin, version 2, Table 3
(3 November 2026). The complete dated primary audit and its limitations
are in [novelty.json](novelty.json). This is a claim relative to that
explicit record, not absolute publication priority. No aperiodic
T-sequence or new real Hadamard order is claimed. The derived **H1524** is
a known-order control; Paley I applies at the prime 1523.

## Exact data and replay

Run the standalone Python/NumPy verifier from any directory:

```sh
python3 /path/to/recipe.py
python3 /path/to/recipe.py --hadamard
python3 /path/to/recipe.py --write-hadamard /tmp/h1524.npz
```

The first command expands all orbit data, checks every one of the 127
periodic correlations, constructs the four literal circulants and checks
their complete summed integer Gram. It also checks the derived coefficient
pair. The optional Hadamard control checks both full frame Grams, every
symmetric cross entry, and all **1,160,526** distinct H1524 row pairs.
Writing refuses to overwrite an existing file. No reference NPZ, search
program or repository module is needed. The script may be renamed
`recipe127.py` provided `t127.json` remains beside it; it does not require
any particular certificate filename.

In `Z_127`, the multiplier `22` has order 9. Enumerate the origin first,
then nonzero multiplication orbits by their least unused representatives.
The states are:

```text
0 0 4 0 1 6 2 3 6 1 0 3 5 4 3
```

State `2*j+epsilon` gives sign `(-1)^epsilon` in channel `j` at the
representative. Multiplication by 22 fixes channel 0 and cycles channels
`1 -> 2 -> 3 -> 1`. These rules determine all four sequences `b_i`;
[t127.json](t127.json) also includes the literal entries. Their row sums
are `(10,3,3,3)` and support sizes `(46,27,27,27)`. Define
`T_i[r,c]=b_i[(c-r) mod127]`. The support sizes are not assertions that
each individual T-matrix is a weighing matrix.

## Scalar-frame control

With the explicit skew conference matrix `D4` in the recipe, put `a=D4*b`.
All 127 coefficient identities are checked, with zero-shift norms
`AA=381`, `BB=127`, mixed term zero and every nonzero-shift sum zero.
The Goethals–Seidel arrays `U=GS(a)` and `V=GS(b)` retain zeros and are
weighing matrices of order 508 and weights 381 and 127. Their complementary
supports give the sign matrices `P=U-V`, `Q=U+V` satisfying

\[
PP^T=QQ^T=508I,\qquad PQ^T+QP^T=508I.
\]

The rational action `R=QP^T/508` represents `zeta_6`, with
`R^T=I-R`, `R^2-R+I=0`. The field is `Q(zeta_6)/Q`, of degree **2**;
its module rank is **254**, with rational dimension **508**. The canonical
trace metric is `[[2,1],[1,2]]`. In the actual Euclidean coordinates,

\[
h(u,v)=u^Tv/2-(u^T(2R-I)v)\sqrt{-3}/6,
\qquad \operatorname{Tr}h(u,v)=u^Tv.
\]

The complete `BH(3,6)` source has diagonal `-1`, off-diagonal `zeta_6`,
used exponent alphabet `{1,3}`, and Gram scale **3**. The frame `F=P`
has scale **508** and maps these entries to `Q` and `-P`. The resulting
sign matrix has diagonal blocks `-P`, off-diagonal blocks `Q`, and order
and Gram scale **1524**. The certificate records the complete actual
rational alphabet of `R`; no flatness is assumed for unused sixth roots.

The reference packed H1524 sign bits have SHA256
`2f90301a69292ef94dfb8cb5d2bd2329b094eebf882e5b1a4bfebfecf1934ef8`.
The independent audit read the actual NPZ, checked its alphabet and
padding, verified every row pair and matched every block to the orbit
recipe. No NPZ binary is included in this bundle; it is regenerated by
the optional command above.

## Files and discovery accounting

- `t127.json`: orbit convention, 15 states, literal b/a sequences and circulant recipe.
- `recipe.py`: standalone exact verifier and optional H1524 writer.
- `independent-audit.json`: independent actual-NPZ, coefficient and scalar-frame audit.
- `novelty.json`: complete dated primary-literature audit.
- `certificate.json`: source/action/frame proof, search parameters, controls and file hashes.
- `README.md`: this description.

The recorded search stream used seed `20261126127`, sampled 289 field
parameters and sent 73 axis words to sign lifting. Its sum of affine-kernel
sizes was 2400; the final kernel stopped at the first zero. It recorded 28
modulo-eight and 19 exact-DC survivors, returning the witness in
`0.00231371` native seconds. These are finite stream counters, not a
rediscovery guarantee or 2400 complete integer-correlation evaluations.
The auxiliary binary field `GF(128)` is distinct from the characteristic-zero
field used in the scalar construction.
