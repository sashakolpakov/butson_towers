# Manuscript-only Hexagon version 3

Revision of the existing article [2611.01070v1](https://hexagonmath.org/2611.01070v1),
*Butson towers and high-rank Hadamard matrices*.

Only **one manuscript file**, `main.tex`, is deposited. Hexagon generates the
PDF from that file. **No ancillary files and no source archive are uploaded.**
All code, data and verification sources remain in the public repository,
which is cited in the manuscript's references.

[Read the manuscript PDF](manuscript.pdf). [build.json](build.json) binds it
to the submitted source and records the warning-free 28-page build.
The [accepted receipt](submission-status.json) identifies **2611.01070v3**
under the same article identifier. The final API commit returned HTTP 202;
the revision is under review. Version 2 remains canceled.

The earlier oversized version-2 package was canceled by the submitter; its
[cancellation record](../hexagon_2611_01070_v2/cancellation-status.json)
is preserved separately. The published first version remains unchanged.
